## パーフェクトコレクション特有の新機能・追加要素

### オンライン機能
※他プラットフォームのプレイヤーとの通信（クロスプレイ）およびセーブデータの共有（クロスセーブ）には非対応です。

#### オンライン対戦
- インターネットを介した対戦プレイに対応
- **カジュアルマッチ**: 同じタイトルを選んだプレイヤー同士で気軽に対戦。初心者向けのレンタルデッキを用意
- **ランクマッチ**: ランクポイントを競い合う本格対戦モード。強い相手とマッチングする仕組み
- **フレンドマッチ**: 部屋を作成して、好きなタイトルで友達と対戦できるモード
- 当時のDS通信対戦がオンラインで楽しめる

#### オンラインカードトレード＆ブラザーバンド
- **カードトレード**: インターネットを介してバトルカードの交換が可能。異なるバージョン間でのカード収集がしやすくなる
- **ブラザーバンド機能**: オンラインでのブラザー登録に対応。登録人数がオリジナル版（最大6人）から**最大100人**まで大幅拡張

### オフライン救済・常設化仕様
通信環境や限定イベントが必要だった要素を、ソロプレイ（オフライン）でもすべて体験できるよう調整されています。

- **『流星2』通信必須トビラのオフライン解放**: オリジナル版で通信が必要だった「封印されたトビラ」が条件を満たすことでオフラインでもすべて解放可能
- **『流星3』隠しボスの常設化**: Wi-Fi対戦時のランダム乱入限定だった「アシッドエースBB」「レッドジョーカーRR」がゲーム内マップの固定ポイントに常設化
- **『流星3』クリア後「ノイズなしロックマン」選択**: ストーリークリア後、あえてノイズチェンジを行わない通常フォームでのプレイが可能

### 新規キャラクターボイス＆ボイス切り替え機能
主要キャラクターのボイスが新規録り下ろしで追加されています。
- **ボイス再生設定**: オプションで「オリジナル準拠（DS版同様）」と「拡張再生（新規ボイスを多用する推奨モード）」を切り替え可能

### ギャラリーモード＆ミュージックプレイヤー
- **ギャラリーモード**: 豊富な設定画、パッケージイラスト、貴重な開発資料、歴史を振り返るアーカイブを閲覧可能
- **ミュージックプレイヤー**: 全作品のオリジナルBGM＋新規アレンジBGMを自由に鑑賞可能

### バトルカード復刻
- **イベント配布カード**を復刻再現
- **玩具特典カード**も復刻再現
- オリジナル版では入手困難だったレアカードが入手可能に

### コラボ・連動要素の再現
- **『ボクらの太陽 Django&Sabata』コラボイベント**: 当時のDS版にあった連動イベントを現代環境で遊べる形で収録
- **ダブルスロット機能の再現**: GBA（ゲームボーイアドバンス）ソフトを挿入することで発生していた連動特典等の仕様も再現

## 快適性向上機能

### アシスト機能（バトル中）
| 機能 | 説明 |
|:---|:---|
| ロックバスター強化 | ロックバスターの攻撃力を増加 |
| 被ダメージ軽減 | 受けるダメージを軽減 |
| オートヒーリング | 自動回復機能 |

### アシスト機能（フィールド上）
| 機能 | 説明 |
|:---|:---|
| 移動速度アップ | フィールド上の移動速度を向上 |
| エンカウント率調整 | 敵との遭遇率を調整可能（増減どちらも対応） |

### グラフィック・操作性・セーブの最適化
- **高解像度フィルター**: ゲーム画面の描画を滑らかにする（オフにすればオリジナル版に近いビジュアルでプレイ可能）
- **オートセーブ**: プレイ中のデータを自動保存（DS版のセーブポイント制から進化）
- **画面レイアウト調整**: 表示サイズやレイアウトのカスタマイズ（DS版の2画面構成を1画面に最適化）
- **操作設定（キーコンフィグ）**: Ver.1.0.1より「決定」と「キャンセル」のボタン割り当て変更に対応

## DS版からの主な変更点

### 大幅改善
| 項目 | DS版 | パーフェクトコレクション |
|:---|:---|:---|
| 対戦機能 | ローカル通信のみ | オンライン対戦（ランク/カジュアル/フレンド） |
| カード交換 | ローカル通信のみ | オンラインカードトレード対応 |
| セーブ | セーブポイント制 | オートセーブ対応 |
| 難易度 | 固定 | アシスト機能（バスターMAX/軽減/回復）で調整 |
| 画面 | DS 2画面 | 調整可能な1画面レイアウト |
| グラフィック | ドット表示 | 高解像度フィルター対応 |
| レアカード | 入手困難 | イベント/玩具特典カード復刻 |
| ブラザーバンド | すれ違い通信 | オンライン対応（100人登録可） |
| 操作設定 | 固定 | 決定/キャンセルボタンの割り当て変更に対応 (Ver.1.0.1〜) |

### 継承要素
- ゲーム本編の内容・ストーリーは完全再現
- 各バージョンの違い（独自カード等）も維持
- アクションRPGとしての基本システムは変更なし
